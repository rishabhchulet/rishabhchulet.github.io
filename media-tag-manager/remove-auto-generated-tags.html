What Wix's automatic image tags are

When you upload an image, the Wix Media Manager tags it automatically, usually with about 20 words describing what it sees in the picture. Wix's Help Center says tags help you organise and find your files, and you can type one into the Media Manager's search bar to find every file that has it.

That is all they do. The tags stay in the Media Manager: they are not shown on your live site and they are not what search engines read. For SEO and accessibility, what counts is each image's alt text, which you set separately in the editor and which tags do not change.

They get in the way when you use tags yourself, to find product shots, sort a portfolio or keep clients' files apart. Your own tags sit in the same list as Wix's, and the automatic ones are often unrelated to the picture. In the Wix Studio forum thread Remove pre programmed tags, open since August 2024, site owners describe deleting them one at a time and ask for a way to remove them in bulk.

Wix's Help Center does not describe a way to switch automatic tagging off, and nobody in that thread has found one. So the tags have to come off after upload: by hand, or with an app.

How to remove the tags by hand

This works on any Wix site and needs no app. It is fine for a few images; each tag on each file is removed separately.

  1. Open the image in the Media Manager

    In the editor, click Media on the left, then Show More under Site Files, and click the image. These are the steps in Wix's Help Center for the Wix Editor and the Studio Editor.

  2. Open its tags

    Click Tags on the right, then Edit tags. You see Wix's automatic tags and any you have added, in one list.

  3. Delete each tag

    Click the × on each tag you don't want, then Done. Then open the next image and do the same.

    People in the forum thread report that tags can't be selected all at once, so each one is removed with its own click. At about 20 tags an image, a library of 100 images is around 2,000 clicks.

How to clear the tags from up to 50 files at once

Media Tag Manager is a free Wix app by Creet that edits the tags on many files in one go, from your site's dashboard. It has no paid plan.

  1. Install Media Tag Manager

    Add Media Tag Manager to your site from the Wix App Market.

    If you also want new uploads cleaned up automatically (below), add Wix CMS to the site before you install the app. Editing tags in batches works without CMS.

  2. Select up to 50 files

    Open Media Tag Manager from your site's dashboard and choose the files to work on, up to 50 in one batch. For a bigger library, work through it 50 files at a time.

  3. Choose what to do with their tags

    • Clear: remove every tag from the selected files.
    • Remove: take off only the tags you pick, and leave the rest.
    • Add: paste a comma-separated list of tags to add to every selected file.
    • Replace: swap the files' tags for a comma-separated list you paste.
    • Copy: give the selected files the tags of one image.

  4. Preview, then apply

    Before anything changes, the app shows a preview of the batch. When you apply it, the original tags are backed up first, and each change is checked after it is saved.

    Clear removes your own tags as well as Wix's, because Wix keeps them in one list. To keep yours, use Remove and pick only Wix's tags, or Clear and then Add your own back.

How to clean up new uploads automatically

Wix tags every new upload as well, so a cleared library slowly fills up again. Media Tag Manager's automatic clean-up clears the tags on each new image once, after Wix has finished processing it, even when the dashboard is closed. After that the file is yours: add your own tags and they stay.

  • It is off until you turn it on.
  • It needs Wix CMS on the site, added before you install the app, and CMS storage limits apply.
  • It does not touch images already in your library or files restored from the trash. Clear those with a batch.

How to undo a batch

Every batch backs up the files' original tags before it changes them. The backups are kept in your site's data or your browser, not on a Creet server, and you can export them. To undo a batch, restore the backup: the original tags go back on the files, and the restore checks for edits made to them since the backup was taken.

What the app can't do

Worth knowing before you clear a whole library.

Tell Wix's tags from yours

Wix keeps its automatic tags and the ones you add in a single list, so clearing removes both. Clear first and add your own afterwards, or remove only the tags you name.

Stop Wix generating tags

The app removes tags after Wix adds them; Wix still tags every upload. The automatic clean-up clears each new image once, so you don't have to.

Change alt text

Alt text is separate from tags and the app leaves it alone. Set it on each image in the editor.

Clean up automatically without Wix CMS

The automatic clean-up needs Wix CMS added to the site before the app is installed. Batch editing doesn't.

FAQ

Do Wix's automatic image tags help SEO?

No. They are for finding files in the Media Manager and are not shown on your live site. Search engines read the image's alt text, which you set separately, so removing tags has no effect on SEO.

Can I stop Wix from adding tags?

Wix's Help Center describes automatic tagging without a setting to turn it off, and the app can't stop it either. Its automatic clean-up is the closest thing: it clears the tags on each new image once, after Wix adds them.

Will clearing delete the tags I added myself?

Yes. Wix keeps its tags and yours in one list, so Clear removes both. Use Remove to take off only the tags you pick, or Clear and then Add your own back.

Does it change my images or their alt text?

No. It changes the tags only. Alt text stays as you set it.

Do I need Wix CMS?

Only for the automatic clean-up of new uploads, and it has to be added to the site before you install the app. Clearing, adding, removing, replacing and copying tags in batches works without it.

What does it cost?

Nothing. Media Tag Manager is free and has no paid plan.
