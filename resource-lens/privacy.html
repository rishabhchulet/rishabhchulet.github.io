Privacy

Last updated: 21 October 2026. Applies to Resource Lens 0.1.

In short: Resource Lens collects no data. It reads your project's files inside your IDE, keeps what it learns in the IDE's memory and caches, and makes no network calls of any kind. The Developer never receives your code or anything about how you use the plugin.

Who we are

Resource Lens ("the Plugin") is a plugin for PhpStorm and other JetBrains IDEs with PHP support. It is made by Rishabh Chulet, an independent developer in India trading as Creet ("the Developer", "we", "us").

What the Plugin reads

To complete, link and check attribute names, the Plugin reads, inside your IDE and only in the project you have open:

  • Laravel migration files under database/migrations directories (not under vendor/), to learn each table's columns;
  • Eloquent model classes, to learn their casts, fillable and appended attributes, accessors, relationships and @property tags;
  • admin panel Resource, form schema, table and infolist classes, to find the model each one uses.

It reads these through the IDE's own code index. It does not run your code, connect to your database or read environment files.

What the Plugin stores

Nothing outside the IDE. What it learns from your files is kept in the IDE's memory and caches while the project is open, and is rebuilt from your files when they change. The Plugin has no settings of its own; the IDE stores your choice to switch its warning or gutter icon off, in your IDE settings, as it does for any inspection or gutter icon.

What the Plugin sends

Nothing. The Plugin makes no network connections: no analytics, no telemetry, no crash reporting, no licence checks, no update checks of its own and no AI services. It contains no error reporter, so if the IDE shows an error that comes from the Plugin, nothing reaches us unless you choose to email it.

What others collect

  • JetBrains: when you install or update the Plugin from the JetBrains Marketplace, JetBrains processes that download under its own privacy policy, and shows the Developer aggregate download and install counts, not who you are. If you write a review on the Marketplace, your review and the name on your JetBrains account are public there. Your IDE's own usage statistics and error reports, if you have enabled them, are governed by JetBrains' policies. See JetBrains' privacy policy.
  • Email support: if you write to support@creet.in, we receive your email address and whatever you include, and use it only to answer you. Please do not send code you are not allowed to share.

Retention and deletion

The Plugin keeps nothing that needs deleting: uninstalling it from Settings | Plugins removes it, and the IDE discards its caches. Support emails are kept for as long as needed to help you and are deleted on request.

Children

Resource Lens is a developer tool and is not directed at children.

Changes

If a future version of the Plugin ever needs to send or store data, this page will say so with a new date before that version is released, and the plugin's change notes will mention it.
